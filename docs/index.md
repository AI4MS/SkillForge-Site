# SkillForge

面向 AI4MS Material Skills 的 Skill 构建与评估资料库。

本站汇总了组内 Skill 开发的操作流程与质量评估标准，供有计算经验的学生/研究者参考、协作、迭代。

## 文档索引

- [**Skill 构建流程操作指南**](skill-construction-guide.md) —— 从零到一构建一个可被 Agent 加载的 Skill，包含目录结构、frontmatter、渐进披露、测试与迭代流程。
- [**Skill 评估框架及评分细则**](skill-eval-rubric.md) —— 八个维度的评分标准（可发现性、清晰度、完备性、一致性、安全性、经济性、可移植性、可维护性），用于打分与改进现有 Skill。
